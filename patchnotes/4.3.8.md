## Patchnotes 4.3.8

This update introduces a new migration framework to update the database schema.
Refer to [INSTALL.md](https://github.com/OpenSlides/OpenSlides/blob/4.3.8/INSTALL.md) for detailed instructions and changes in the update process.

### Security improvements
- Restrict motion comment actions to those who can see the motion
- Reduce permissions on user-related presenters

### New Features
- Consultation sequence: The consultation sequence displays all forwardings of a motion along with the motion’s state, provided that visibility for participants is not restricted. This feature can be disabled in the meeting settings. 

### Optimizations
- Projector > List of speakers: The title of the item is abbreviated so that the subheading remains on a single line.
- Various UI optimizations, including improved display of the mandate check

### Improved Accessibility
- Motions > Motion metadata: Editing buttons now have ARIA labels for screen readers.

### Bug Fixes
- Agenda > Import: Data from all columns of the import file can now be imported.
- Agenda > Import: Duplicate agenda items can now be imported.
- Motions > Change recommendations: The row selection for change recommendations is correct.
- Motions > Amendments: Changes that include formatting are displayed more clearly.
- Votes: Ending a vote does not result in the loss of votes if participants’ attendance status is changed at the same time.
- Projector > Timer: If the device time differs from the server time, this difference is factored into the displayed timer.
