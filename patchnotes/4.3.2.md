
## Patchnotes 4.3.2

### New Features
- Elections: Sorting feature added. The list of candidates can be sorted by first name or last name using the sorting feature.

### Optimization
- Account Admins: The "Home committee" field and "external" status have been removed as options when creating and editing accounts.
- Motions > Detail View: Performance improvement
- UI optimizations

### Optimizes accessibilityi
- List views with details: Details such as tags, groups, structure levels, etc., have been assigned with ARIA labels and can be read aloud by screen readers.
- Custom sort and filters, number of speakers, and other badges are now reachable for screen readers.

### Bug Fixes
- Dashboard > Settings: The Save button is now visible only after a change has been made.
- Option selections in various menus (history, duplicate from) now work correctly again.
- Motions > Amendments > Change recommendations: Headings can be changed with change recommendations.
- Motions > Amendments: Even if a main motion has a category, participants can once again create amendments.
- Motions > Metadata > Status: The order of statuses in the metadata now matches that in the workflow.
- Motions > Creation: Motions can now be created reliably, and users are immediately redirected to the motion’s details page.
- Motions > PDF Export: Motions whose title or identifier contains dots are exported as PDF documents.
- Motions > Amendments: When you add the first change recommendation, the text view switches to the Diff view.
- Motions > Forwarding: Motions can now only be forwarded to upcoming meetings. Forwarding to past or timeless meetings is not supported.
- Motions > Amendments > Justification: The reason text is displayed at full width and scaled correctly.
- Speaking Times > Interposed questions: When switching from an interposed question to a subsequent contribution (answer or another interposed question), the system switches to the speaking time of the person currently speaking and displays it.
- Projection > Chyron: The font enabled for the speaker’s name in the chyron is used only for the first and last names.
- Livestream: The livestream loads correctly.
- Password reset feature: If supported, emails are sent in the user's browser language, otherwise they are sent in the organization's language.
